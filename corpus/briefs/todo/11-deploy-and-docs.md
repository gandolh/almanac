# Task 11: Container, VPS stack, Ward entry and the owner's docs

## Context

Almanac runs on the shared VPS like Shelfmark: Caddy serves the web app at
`/almanac/` and forwards `/almanac-api/` to the API container on
`127.0.0.1:8797` ([decisions.md](../../wiki/decisions.md), "Deployed on the
VPS"; [architecture.md](../../wiki/architecture.md) "Request paths").
Shelfmark's commit for the same work in `../vps-deploy` is `1c5438b`; copy
its shape. Deploying, pushing and creating secrets are owner steps: write
the commands down, never run a deploy.

Depends on: 01 and 02 (the server, its env keys and seed). Can run beside the
web briefs; it touches no app source.

## What to do

1. **Container**: copy Shelfmark's `infrastructure/Dockerfile` (node:24-alpine,
   deps / builder / proddeps / prod stages, `COPY server/vendor`, tests
   deleted from dist, `HOST=0.0.0.0 PORT=8797 DATA_DIR=/data`, `VOLUME
   /data`, the wget healthcheck on `/api/health`) and `docker-compose.yml`
   (service `almanac-api`, image `almanac-api:1.0`, `127.0.0.1:${ALMANAC_PORT:-8797}`,
   `env_file: .env`, data volume `${ALMANAC_DATA_DIR:-../data}:/data`). Mind
   the trap that the compose `environment:` block beats `env_file`. Build it
   locally with `docker build` if Docker is reachable; say so if it isn't.
2. **vps-deploy**: `stacks/almanac.ts` as a `WebServiceStack` copied from
   `stacks/shelfmark.ts` with `basePath: "/almanac"`, `apiPrefix:
   "/almanac-api"`, client build with `baseEnv: "ALMANAC_BASE"`, remote dir
   `/var/www/almanac`, server dir `/srv/almanac-api`, service `almanac-api`,
   port 8797, persistent data dir, no Google key. Register it like Shelfmark:
   `lib/estate.ts` source repo `../almanac` with `workspaceRoot: true`,
   `app.ts` construction plus `useWard(ward.identityFor(almanac,
   "almanac"))` and the trailing list. Run `node cli.ts synth` and
   `node cli.ts --check`; both must pass. Also update the listings
   Shelfmark's commit missed for itself, adding rows for **both** Shelfmark
   and Almanac: `docs/stacks.md`, the stack counts and graph excerpt in
   `README.md`, `docs/usage.md` (edge count), `docs/getting-started.md`
   (checkout list). Commit in `../vps-deploy` on its `main`: one commit, no
   push.
3. **wzd_auth**: add `{ slug: "almanac", name: "Almanac", repo: "almanac",
   envFiles: [".env"], dev: "http://localhost:5177/almanac/", api:
   "/almanac-api" }` to `APPS` in `infrastructure/local/seed.mjs`, and the row
   to `infrastructure/local/README.md`. Commit in `../wzd_auth` on its

4. **docs/owner-setup.md**: Shelfmark's structure, minus the Google Books

5. **README.md**: short: what Almanac is (two or three sentences), the

   the docs and the corpus are. No screenshots yet.
